The v1 proof test

Five checks on your oldest tablet

This is the pass/fail test from the Forge Browser research. Run it on the actual frozen device — an iPad stuck on iOS 9 counts. Steps 1–4 must pass; step 5 must fail gracefully, with a clear message instead of a blank player.

  • 1Cold load. Open this page on home Wi-Fi. The address bar and search box render, and the pill at the top flips to “JS OK”.
  • 2Search. Type an artist and submit. Results appear with covers and preview buttons.
  • 3Play. Tap a result. Audio starts within about 5 seconds, plays to the end of the 30-second preview, and pause / next / previous all respond to taps.
  • 4Browse. Type a plain article URL in the address bar. It renders in the viewport above — or Forge tells you plainly if the site refuses to be framed.
  • 5Honest failure. Tap Spotify, Apple Music or Pandora above. Forge shows the “previews only” notice up front — never a silent, dead player pretending it will work.
Your services, straight answers

What works here — and what can't

Forge is one web page running inside your tablet's existing browser engine. On iPads that engine is WebKit for every browser — so no page can install a new DRM module or media engine. Here's each service against that wall:

S
Spotify Previews only

Forge plays Spotify-style 30s MP3 previews. Full playback needs Premium + Widevine DRM via the Web Playback SDK — Widevine doesn't exist on any iOS surface. Web player now requires Chrome 87+ / Safari 15+.

Internet radio & podcasts Plays in full

DRM-free MP3/AAC streams are the one format old Safari has played since the beginning. Full stations, full episodes — this is Forge's home turf.

Why not just log in through Forge? A proxy login would have to hold your password, MFA code and session cookie — a breach there is a breach of your whole music account, and OAuth sign-ins break when they arrive from the wrong domain. V1 refuses that design on purpose.

How v1 is wired

Old tablet (frozen WebKit, ES5 only) └─ Forge shell: 1 static page ├─ Address bar → simplified page view ├─ Search → catalogue API → title / cover │ + preview_url (plain MP3) └─ <audio src=preview> plays directly No MSE · No EME · No login proxy

Next gates, in order: ① a small always-on helper (~$5–7/mo class) so first search doesn't cold-start; ② sanctioned embeds where they help; ③ a separate native cloud-browser app for full catalogues — explicitly not code-only, with its own cost and legal review.
