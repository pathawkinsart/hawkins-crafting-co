▶ My Pandora station

Spotify YouTube Music Apple Music iHeartRadio TuneIn Radio My own music — Forge Player
If Pandora says “Get the App”:
1. If the app will install on that iPad, install it once, then come back here and tap Open Pandora again — it should jump into the app.
2. If the app will not install because the iPad is too old, try Safari > Share > Request Desktop Website, then tap Open Pandora again. It does not always work, but it is worth one try.
3. If neither works, use My own music above — that player is plain audio, no account, and it does work on old browsers.
