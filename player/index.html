Drop songs, a folder of songs, cover.jpg, or record.jpg here.
Cover and record art are matched by folder: a cover.jpg / folder.jpg or record.jpg / disc.jpg in the same folder as a song is shown for that song.

How song names are shown: artist and album are taken from the folder path (for example, Artist / Album / song) or from an "Artist - Title" filename. Embedded tag art is not read by this page — if a song shows no art, add a cover.jpg in its folder and pick it again. No metadata is invented.

Sync

There is no auto-sync on this page.
No sync is ever reported as completed unless you actually picked the files. This page has no server, so it cannot push your saved songs to another device by itself.

How to get the same songs on another device, by hand

  1. On the other device, open this same page in its browser.
  2. Pick the same song files there — from that device's own storage, a USB drive, an SD card, or a cloud drive you open yourself and download from. Picking them there saves them in that browser only.
  3. Use the same folder shape if you can (Artist / Album / song, with cover.jpg and record.jpg in the album folder), so the art matches the same way.

A future "same music anywhere" would need a cloud or server place to hold the files, plus an account to keep them private. That is not built here, by the locked choice for this page: browser saving, same device only.

Junior-lite — browser-safe jobs only

Junior-lite here is a checklist and a few browser tools. It cannot do Fire-only jobs in a browser.

2. Backup (list only)

Backup exports a JSON list of your saved songs (titles, artists, albums, sizes) — it does not export the audio files themselves. Keep the original song files to restore playback.

3. Cleanup guidance

Keep songs in Artist / Album folders, with cover.jpg for album art and record.jpg for the round disc photo. Remove a saved song with its Remove button in the Local list, or clear everything below. Removing a saved song deletes only the browser's copy — it does not delete your original file.

4. Fire-only jobs — not available in a browser

Debloat / disabling Amazon apps, Bluetooth and speaker system settings, and Fire system settings are Fire-tablet jobs only. They are not claimed, and not attempted, on this web page.
